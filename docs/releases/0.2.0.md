# FotoSort v0.2.0 — review and evaluation preview

This experimental preview adds a local workflow for correcting photo selections,
preserving those choices, and measuring saved results against photographer feedback.
Photo-selection thresholds and model weights are unchanged.

## What's new

- **Persistent decisions:** `fotosort decisions` records keep/reject choices,
  notes, pairwise preferences, and acceptable alternatives. Choices survive
  analysis reruns, while reports preserve the automatic recommendation separately.
  Undo and reviewed CSV export require no model calls.
- **Visual reviewer:** `fotosort review` opens an existing report in a local
  browser. Compare selected and excluded neighbours with synchronized detail
  views, record feedback with keyboard shortcuts, and export reviewed selections.
  Images and review requests remain local.
- **Offline evaluation:** `fotosort evaluate` exports feedback, evaluates saved
  reports, and compares frozen baselines and candidates with matching inputs and
  declared budgets. It separates exact-frame and acceptable-moment recall,
  shortlist exposure and final selection, and human corrections and automatic
  picks. Partial coverage has explicit bounds and unknown results.
- **Safer review/export:** content verification detects changed sources before
  reviewed export or RAW culling. Concurrent review edits are preserved or cause
  an explicit conflict. Evaluation summaries cannot replace inputs or review data.

See the [review guide](https://github.com/JRS1986/FotoSort/blob/v0.2.0/docs/review.md),
[evaluation guide](https://github.com/JRS1986/FotoSort/blob/v0.2.0/docs/evaluation.md),
and [changelog](https://github.com/JRS1986/FotoSort/blob/v0.2.0/CHANGELOG.md).

## Install or upgrade

Requires Python 3.11+ on macOS or Linux. Download the attached wheel and install
it in your virtual environment:

```bash
python -m pip install --upgrade ./fotosort-0.2.0-py3-none-any.whl
```

For optional judge clients, append `[judge]` to the quoted wheel path. Alternatively,
extract the attached source archive and run `python -m pip install ".[judge]"`
inside it. The source archive includes label examples, tests, and evaluation docs.
`SHA256SUMS` records the SHA-256 hashes of both attached distributions.

```bash
# Review an existing report without reanalysis or judging.
fotosort review /path/to/photos

# After exporting the reviewed CSV, explicitly copy the chosen photos.
fotosort /path/to/photos --apply-report --report fotosort_reviewed.csv --copy

# Freeze explicit feedback and measure the saved automatic result.
fotosort evaluate feedback /path/to/photos --output /path/to/private-evaluation.json
fotosort evaluate run /path/to/private-evaluation.json --output summary.json
```

Legacy CSV reports remain readable; missing historical hashes cannot establish
past content identity. Regenerate reports from intermediate previews that let
`--include` alter automatic eligibility before evaluating automatic recall.

## Scope and limitations

Validation passed: 307 local tests, Ruff, JavaScript syntax, isolated source and
wheel builds, and strict Twine metadata checks. Installed-package checks outside
the checkout cover CLI entry points, reviewer assets, and offline evaluation with
0.2.0 provenance. CI covers Python 3.11 and 3.12, including packaging and installed
CLI checks.

Selection remains heuristic and can miss a preferred frame. This release does
not establish improved photographic accuracy. Review originals before discarding
anything; FotoSort preserves photo contents and requires explicit flags for moves,
exports, and sidecar writes.

Feedback is recorded for later learning; it does not yet train a personal ranking
model. Incremental analysis/judge resumability and live evaluation orchestration
remain planned. The harness evaluates saved reports without model or API calls.
Private feedback manifests contain filenames; shareable summaries omit filenames
and notes but are not a guarantee of anonymity.

The local reviewer and decision store target POSIX systems. Camera-specific RAW,
DxO, live cloud judging, and broader photographic accuracy are not revalidated by
this release's logic and packaging checks. Cloud judging remains opt-in.
